# UE Projesi

Unreal Engine 5 ile geliştirilen oyun projesi

## Sistem Gereksinimleri
- Unreal Engine 5.x
- Visual Studio 2022
- Windows 10/11

## Kurulum
1. Depoyu klonlayın
2. `.uproject` dosyasını sağ tıklayın → "Generate Visual Studio project files"
3. Visual Studio'da build edin
4. UE Editor'de açın
